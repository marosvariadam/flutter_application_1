# Mobile App Frontend

Ez a repository a szakdolgozatom kliensoldali komponensét tartalmazza. Az alkalmazás egy cross-platform mobilmegoldás, amely Android és iOS rendszereken is futtatható.

## Technológiai háttér

A projekt a következő technológiák felhasználásával készült:

- Keretrendszer: Flutter
- Nyelv: Dart
- Architektúra: Komponens alapú UI, State Management
- Kommunikáció: HTTP kliens a REST API eléréséhez

## Funkcionalitás

Az alkalmazás az alábbi fő funkciókat látja el:

- Reszponzív felhasználói felület (UI) megjelenítése
- Kapcsolattartás a szerveroldali backenddel (ASP.NET Core)
- Felhasználói adatbevitel kezelése és validálása
- Dinamikus tartalom megjelenítése

# Mobile App Frontend

This repository contains the client-side component of my thesis project. It is a cross-platform mobile application capable of running on both Android and iOS systems.

## Technical Stack

The project is built using the following technologies:

- Framework: Flutter
- Language: Dart
- Architecture: Component-based UI, State Management
- Communication: HTTP client for REST API access

## Functionality

The application provides the following main functions:

- Responsive user interface (UI)
- Communication with the server-side backend (ASP.NET Core)
- User input handling and validation
- Dynamic content display
